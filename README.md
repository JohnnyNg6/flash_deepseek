# DeepSeek-R1 Flash Inference on M2 Ultra

Running DeepSeek-R1 671B (Q4_K_M) on Apple M2 Ultra 192GB 
using concepts from "LLM in a Flash" (Apple, 2023).

**Model:** DeepSeek-R1-Q4_K_M (671B MoE)  
**Hardware:** Apple M2 Ultra, 192GB unified memory, 4TB SSD  
**Throughput:** 1.5–2 tok/sec

## Acknowledgements

This implementation is inspired by 
[danveloper/flash-moe](https://github.com/danveloper/flash-moe), 
which pioneered SSD expert streaming for MoE models on 
Apple Silicon (Qwen3.5-397B on 48GB). My setup uses more 
generous hardware (192GB) but applies similar principles.
